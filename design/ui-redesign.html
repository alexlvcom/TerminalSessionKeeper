Keep between 1 and 500 snapshots.

A snapshot is a few KB. Nothing is written when no tabs are open, so a good snapshot is never replaced by an empty one.

After a reboot

Put the tabs back automatically after a reboot Only on the first run after a reboot, and only when no terminal window is already open — restoring beside a live window would put both into the next snapshot.
Run each resume command instead of leaving it at the prompt Off by default: a dozen agents and their MCP servers all starting at once, right after a reboot, is rarely what you want.

Restore window

Rebuild tabs into a new window named Every restore opens its own window and the name carries the time it ran, so a restore never adds its tabs to the window an earlier one built.

Restored WSL tabs

Added only to the WSL tabs a restore opens. Tabs you open yourself are not affected.
Type a cd into each restored WSL tab Runs cd into the tab's saved folder once its shell has started, in case the shell changed directory while starting up. Turn it off if yours does not.

App theme

Theme System follows your Windows light or dark mode and changes with it.

Restored tabs

Keep saved tab titles, even when the shell renames a tab Otherwise a restored tab keeps its saved title until the shell or the agent renames it, which is usually what you want.
Remember tab colours Windows Terminal exposes no API for tab colours, so the window is asked to render itself and the colour is read from the tab's own pixels. A colour has to be read the same twice before it is kept.
Put tab colours back when tabs are rebuilt Applied the way the colour picker applies one, so the picker's Reset clears it again. Needs a setTabColor action in Windows Terminal's settings.json for a second or two; it is removed straight afterwards.

Terminal Session Keeper v1.3.2

Built 2026-10-20 • by alexlvcom
Release notes for v1.3.2: View full change history

Main changes

  • Settings now saves every preference, including the update check frequency, only when you click Save. Cancel, Esc, or closing the window discards all unsaved changes, so Cancel always undoes a frequency change.
  • Save reports an error and keeps Settings open with your edits when settings.json cannot be written, instead of closing as if it had worked.

Other updates

  • Settings are written through a temporary file so a failed save never leaves a half-written settings.json.
  • Saving Settings keeps the last update check time recorded while the window was open.
